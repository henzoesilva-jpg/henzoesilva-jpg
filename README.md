## 🎯 Foco atual: Engenharia de Dados

Minha transição para Engenharia de Dados é uma jornada de aprendizado contínuo. Quero compreender não apenas como manipular dados, mas também como estruturar processos confiáveis para coletá-los, transformá-los, armazená-los e disponibilizá-los para análise.

### Minha trilha de desenvolvimento

**01 — Fundamentos**

- Fortalecer Python aplicado a dados.
- Evoluir em SQL e consultas relacionais.
- Estudar modelagem de bancos de dados.
- Praticar Git, Linux e organização de código.

**02 — Construção de pipelines**

- Desenvolver pipelines ETL/ELT com Python e SQL.
- Trabalhar com extração, limpeza e transformação de dados.
- Implementar verificações de qualidade e integridade.
- Registrar erros e organizar processos de execução.

**03 — Ambiente e ferramentas**

- Aprofundar os conhecimentos em PostgreSQL.
- Aprender Docker para criar ambientes reproduzíveis.
- Explorar dbt para transformação e documentação de dados.
- Estudar Apache Airflow para orquestração de workflows.

**04 — Escala e nuvem**

- Conhecer os fundamentos de computação em nuvem.
- Explorar Apache Spark e processamento distribuído.
- Estudar arquitetura de pipelines escaláveis.
- Compreender monitoramento, confiabilidade e custos de processamento.

O progresso entre essas etapas dependerá da consolidação dos fundamentos e da aplicação prática dos conhecimentos em projetos.
